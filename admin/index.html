تسجيل الدخول للوحة التحكم

اللوحة تعمل عبر GitHub مباشرة (مجاني بالكامل). تحتاج Personal Access Token مرة واحدة فقط — خطوات إنشائه تحت.

إنشاء التوكن: github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → في Repository access اختر Only select repositories وحدد ريبو الموقع → في Permissions افتح Contents واجعله Read and write → Generate → انسخ التوكن والصقه هنا. التوكن يُحفظ في متصفحك أنت فقط.
